ทุกตัวเลขในหน้านี้ รวมถึงยอดใช้สะสม จะนับเฉพาะแคมเปญในรายการนี้ · หา ID ได้จาก URL ใน Ads Manager (selected_campaign_ids=…)
วิธีขอ token
  1. ทดสอบเร็ว (หมดอายุใน 1–2 ชม.): เปิด Graph API Explorer → เลือกแอปของคุณ → Permissions เพิ่ม ads_read และ read_insights → Generate Access Token → คัดลอกมาวาง
  2. ใช้ยาว (ไม่หมดอายุ): Business Settings → Users → System Users → สร้าง system user → Assign asset = บัญชีโฆษณานี้ → Generate token เลือก ads_read
หน้านี้เรียก graph.facebook.com จากเบราว์เซอร์ของคุณโดยตรง token ไม่ถูกส่งไปที่อื่น
ลิงก์แบบมีรหัส: token ถูกเข้ารหัส (AES-256 + PBKDF2) แล้วแนบท้ายลิงก์หลัง # เปิดได้เมื่อใส่รหัสเท่านั้น · ลิงก์แบบไม่ต้องใส่รหัส: token อยู่ในลิงก์ตรงๆ ใครมีลิงก์ก็เห็นข้อมูลโฆษณาได้ทันที — ส่งเฉพาะคนที่ไว้ใจ ถ้าหลุดให้ยกเลิก token ใน Meta · ส่วนหลัง # ไม่ถูกส่งไปเซิร์ฟเวอร์ใด · ควรใช้ System User token ที่ไม่หมดอายุ
